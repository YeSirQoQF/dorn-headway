## 玩法

发射小圆去撞漂浮的大圆：碰到就粘成一只耳朵；两只耳朵正对着贴好，头就完成了。把完整的头送到经过的身体旁，它会自动接上、直接出厂。

别让场上的东西砸到身体——受击攒满 3 点掉 1 血，血掉光就是炸单；没接到头的身体算空车。连续炸单太多，本局结束。送达率越高，评价越好。

场上的球带电荷：小球带负电、大球带正电、组装出的头恰好不带电。按住 `W` / `S` 撑起全场电场，推拉所有带电的圆——按住右键还能放慢时间，从容瞄准。

## 模式

点击“开始游戏”先选模式：

- **经典模式**：上面的全部规则，比拼送达率。
- **合成大黑洞**：保留全部机制，目标改为让黑洞活得尽可能久。黑洞按 `M(t) = M₀·(1 − t/T)^(1/3)` 的曲线随时间衰变，新黑洞的存活总时间 T 为 6 秒，质量越大 T 越长（与质量三次方成正比）；吞噬物体则增长质量——吞噬完整的身体比空车增重更多。两个黑洞相遇时质量小的消散、大的继续计时，并继承对方的质量。记录最长存续、最大吞噬与最大增重（质量相对初始的增量），此模式强制不败。

## 道具

用 `R` / `F` 或滚轮切换：

- **气球**：飞得极快的小球，碰到东西就碎，给身体 1 点受击
- **炸弹**：碰哪炸哪，炸毁附近的物体，贴到身体上会扣 4 滴血
- **黑洞**：吸引并吞掉一切靠近的东西，碰到身体直接炸单，几秒后自行消散

## 操作

| 操作              | 方法                                                                 |
| ----------------- | -------------------------------------------------------------------- |
| 鼠标 / 触屏       | 移动瞄准，点击或轻点发射                                             |
| `A` / `D`         | 左右移动发射点                                                       |
| `R` / `F`、滚轮   | 切换道具                                                             |
| `W` / `S`（按住） | 释放竖直电场：`W` 向上（小球向下推、大圆向上拉）；`S` 向下、效果相反 |
| 右键（按住）      | 放慢全场时间                                                         |
| 键盘              | `空格` 发射，`ESC` 暂停                                              |

## 设置

**游戏模式**

- **不败模式**：永远不会失败，放心练手
- **严格模式**：接到头后身体仍会受击，每 3 次受击掉 1 血
- **飙速模式**：身体以最密节奏接连出场，一个紧挨一个

**游戏机制**

- **黑洞膨胀**（默认关闭）：开启后黑洞半径随质量线性增大（质量 4096 时为最小半径，8192 时翻倍）；关闭时固定为最小半径
- **显示黑洞质量**（默认开启）：在黑洞下方实时显示它的当前质量
